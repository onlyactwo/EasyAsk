# EasyAsk

轻量的 macOS 菜单栏 AI 提问工具，使用 DeepSeek V4.1 Flash（API 模型名 `deepseek-flash`）。

本项目以 [MIT 许可证](LICENSE)公开。

## 下载与运行

仓库中的 `dist/EasyAsk.app` 是预编译版本，适用于 **Apple 芯片、macOS 15 及以上**。克隆仓库或从 GitHub 下载 ZIP 并解压后，可以先尝试打开它。这个版本使用开发者电脑上的本机证书签名，没有 Apple Developer ID 签名或公证；macOS 可能阻止首次打开。若确认来源可信，可在尝试打开后前往“系统设置 → 隐私与安全性”选择“仍要打开”。此预编译版本不保证在其他 Mac 上直接运行。

应用内没有预置 API Key 或聊天记录。每位使用者都需要在设置中填写自己的 DeepSeek API Key。飞书在线文档导出还需要本机安装、登录 `lark-cli`。

## 自行构建

适配 macOS 15 及以上。需要 Apple Command Line Tools，不需要安装完整 Xcode。构建脚本会为这台 Mac 创建专用的本机签名身份；首次运行 `setup-signing.sh` 时需要批准系统钥匙串授权。

```sh
./setup-signing.sh  # 首次构建运行一次，创建本机签名身份
./build.sh
open dist/EasyAsk.app
```

首次设置会在本机创建专用的代码签名证书和钥匙串，不需要 Apple 开发者账号或完整 Xcode。该证书不受其他 Mac 自动信任；若要正式分发可直接打开的应用，仍需 Developer ID 签名和 Apple 公证。

双击应用或点击菜单栏图标，会在图标下方打开提问面板；点击界外时面板自动收起。收起后应用仍在菜单栏运行，以便随时打开或使用全局快捷键。侧栏左下角可进入设置，其中的“退出 EasyAsk”会彻底结束进程并移除菜单栏图标。全局快捷键默认关闭，可在设置中自行录制或清除。

设置中的“重启 EasyAsk”会启动同一应用的新进程，成功后再退出旧进程。回答生成期间重启按钮不可用。

界面采用简洁的暖阳主题：奶油色侧栏、橙色操作重点，以及从侧栏边缘探出的角色。新聊天页保留一句提示和输入框，历史列表只显示聊天标题。

菜单栏图标由 macOS 排列。如果图标落在屏幕刘海左侧，按住 `⌘ Command` 拖动 EasyAsk 图标到右侧图标组中想要的位置；图标具有固定标识，以便系统保存排列。

## 使用

1. 在设置中输入 DeepSeek API Key。支持 `⌘V`，也可点击输入框旁的“粘贴”按钮；点击“保存”后生效。
2. 输入文字提问。可以按 `⌘V` 粘贴剪贴板图片，或点击图片按钮；图片只随本次请求发送，不写入历史。
3. 点击输入框旁的“思考模式”会在按钮上方打开小面板，可在其中启用思考并选择 low、high、max 三档，初始为 high。发送消息后会保持当前选择，直到你手动修改；重新启动应用时思考默认关闭。
4. 可在同一段聊天中追问，并在左侧删除整段聊天。
5. 在聊天标题右侧点击“导出”，可将该段完整聊天整理成一份总结性文档，直接保存为本地 Markdown，或通过本机飞书 CLI 创建在线飞书文档。导出会单独调用一次 DeepSeek，不会把整理结果加入聊天记录。目前不导出图片。

导出飞书文档需要本机已安装并配置 `lark-cli`，且已用用户身份登录并取得文档权限。EasyAsk 不保存飞书凭证；导出时调用本机 CLI，成功后打开新建的文档。Markdown 导出会先让你选择保存位置，再开始生成内容。

设置里的“回答自动跟随”默认关闭。开启后，回答流式输出时聊天区自动滚到末尾；手动上滚会暂停跟随，回到底部后恢复。离开底部时可点击聊天区右下角的向下箭头直接返回。该选择保存在本机。

AI 回答按 Markdown 显示，支持标题、列表、引用、代码块、表格及常见行内格式；你输入的原文仍按纯文本显示。
每条 AI 回复下方的“复制回复”会复制回答原文（保留 Markdown 标记），不包含思考过程。

聊天记录保存在本机的 `~/Library/Application Support/EasyAsk/history.json`。API Key 保存在本机钥匙串中，不通过 iCloud 同步。发送提问时，当前文字与图片会传给 DeepSeek API；追问时会传送该聊天的文字历史，历史图片不会再次传送。

如果旧版本的密钥在重新构建后无法读取，需要在设置中重新输入并保存一次。之后本地构建会复用同一个签名身份，避免更新代码后再次失去钥匙串访问权限。
